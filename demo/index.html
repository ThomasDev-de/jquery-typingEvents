jquery-typingEvents

Live demo for key filters, typing start/end, and auto-trim.

1) Basic Typing

Typing start/end is triggered during normal input (delay 400ms).

2) Allowed Keys

Only numbers, dot, and minus are allowed.

3) Prevented Keys

Space and comma are blocked.

4) Trim + Delay

Trims from both ends: .,|]\\^ (delay 900ms).
